# 2. Small Site
The smallest site we can consider is one with <=48 points with 90m.

<figure>
<img src = "https://jor-donegal.github.io/WiredL1/images/fig9.jpg">
<figcaption>Fig 9. A minimal site.</figcaption>
</figure>

This could use a single wall mounted cabinet and will just need CAT6 cabling. This describes most small offices, rural schools etc. in Ireland, perhaps 90% of all sites! 

Any node will connect via a patch cable to a telecommunications outlet (TO). The plate presents an RJ45 connector and the patch lead is <=5m long.

<figure>
<img src = "https://jor-donegal.github.io/WiredL1/images/fig9.jpg">
<figcaption>Fig 9. A telecom outlet (TO).</figcaption>
</figure>

At the back of the TO, a four-pair CAT6 cable is punched down onto the IDC connections using a punch-down tool.

<figure>
<img src = "https://jor-donegal.github.io/WiredL1/images/fig10.jpg">
<figcaption>Fig 10. An IDC punchdown tool.</figcaption>
</figure>

That grey cable runs through containment for <=90m, egressing in a rack. In the photo, the cable is <1m.

<figure>
<img src = "https://jor-donegal.github.io/WiredL1/images/fig11.jpg">
<figcaption>Fig 11. End to end.</figcaption>
</figure>

In the rack is a patch panel. The four-pair CAT6 cable is punched down onto the IDC connections of the patch panel using a punch-down tool.

<figure>
<img src = "https://jor-donegal.github.io/WiredL1/images/fig12.jpg">
<figcaption>Fig 12. IDC at the patch panel.</figcaption>
</figure>

Any node will connect via a patch cable to a telecommunications outlet (TO). The patch panel presents an RJ45 connector and the patch lead is <=5m long. This will normally connect to a switch but any services may be presented through this infrastructure. The phot shows two POTs lines and two ISDN lines.
