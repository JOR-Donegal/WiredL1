# Campus Site
The normal definition of a campus is a single site with more than one building.

If we can’t reach all our clients in 90m or if we have multiple buildings, we will normally have more than one wiring location. We do not run copper computer cables outdoors, too many issues with EMP, lightning etc. We try to use fibre optics for our inter-building connections. Beware, fibre is not an infinite pipe.  You need to match the optics with the fibre type, distance and required bandwidth. On a campus we will normally use multi-mode fibre, OM4 has been in common use, OM5 is relatively new (c. 2021).

We do run general purpose copper cable between buildings, but we use it for telephony etc. We fit lightning arrestors to any conductive cables we run outdoors.
