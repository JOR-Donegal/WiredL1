# Radio
We use radio technologies for some very particular use cases, but in almost any infrastructure, we rely primarily on cables and fiber.
Wi-Fi is ubiquitous for laptop and mobile devices, and Wi-Fi access points (APs) are normally wired back to a central network.
Bluetooth and other low-power radio technologies are used for peripherals.

There are specialist frequencies and technologies for Internet of Things (IoT) devices. I use 433MHz and 866MHz devices for many applications.

In places like Donegal, we can use Point to Point Microwave links where fiber is not available. The design of these links is a specialized job, I will not go into detail here.

Also in rural areas, when we want to connect broadband to homes and businesses, we need a "last mile" technology. We also use microwave links for this and technologies like WiMAX.
